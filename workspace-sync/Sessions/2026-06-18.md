## What was done this session

Built and debugged `CoilingState.cpp`, a new Sierra Chart ACSIL study that detects pre-ignition coiling state by computing proximity scores across up to 40 triggers (based on the CBBOAC trigger framework). The study outputs green/red dots at bars where a minimum number of triggers are coiling.

Key work:
- Initial build of CoilingState.cpp with 63 subgraphs (SG0–SG62)
- Diagnosed why the long (green) dot never appeared: Sierra Chart's 60-subgraph hard limit silently clips SG indices > 59 to slot 59. The last SetDefaults write to slot 59 wins — which was "CoilAlertShort", making the long alert invisible.
- Fixed by removing 3 subgraphs: SG_MACD_LINE (computed inline instead), SG_SCORE_LONG, and SG_SCORE_SHORT. Total reduced to 60 (SG0–SG59).
- Renumbered all #defines down by 1 after SG_MACD_SLOW to account for removed SG_MACD_LINE.
- Updated MACD signal computation to use an inline `macdLineNow` variable instead of a stored subgraph.
- Used sc.GraphName = "CoilingState v1.1" as a DLL load canary to confirm fresh compiles were taking effect.
- User confirmed fix worked ("works now").

Also discussed:
- CoilThreshold=1.0 semantics: means all sub-conditions must be fully satisfied simultaneously, not pre-ignition detection. Useful range is 0.70–0.85 for pre-ignition.
- Whether threshold=1.0 on a 10-range chart replicates CBBOAC prints: not identical — CBBOAC uses exact trigger logic (SMI, per-price VAP thresholds, NYSE Tick) vs CoilingState's proximity approximations.
- Feasibility of exact CBBOAC replication in a single self-contained ACSIL study: confirmed feasible for all 38 active triggers minus T17/T18 (NYSE Tick), with additions needed: per-price VAP lookups, SMI implementation, price BB for T37/T38, ±300 vol-at-price for T28/T30.

## Decisions made

[2026-06-18] Decision: Remove SG_MACD_LINE, SG_SCORE_LONG, SG_SCORE_SHORT to stay within SC's 60-subgraph limit. Why: SC silently clips indices > 59 to slot 59; multiple SGs writing to the same clipped slot causes the last write to win, making earlier SGs invisible. MACD line computed inline; score SGs were display-only and not required for alert logic.

[2026-06-18] Decision: Use sc.GraphName change ("CoilingState v1.1") as DLL load verification canary. Why: After restarting SC, old subgraph layout persisted — needed a reliable way to distinguish "DLL not reloading" from "DLL reloaded but structure is wrong."

[2026-06-18] Decision: Set CoilThreshold default range to 0.70–0.85 for pre-ignition detection, not 1.0. Why: Threshold=1.0 requires all sub-conditions fully met simultaneously, which means triggers have already fired — not pre-ignition. 0.70–0.85 catches conditions coiling toward a trigger without having crossed it yet.
